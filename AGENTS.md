# Project Rules — Jobz.pk Tender Batch Downloader

1.  Chromium Manifest V3 extension.
2.  Popup activation only in Version 1.
3.  Process only the currently opened tender pagination page.
4.  Never automatically move to another pagination page.
5.  No OCR.
6.  No PDF generation.
7.  No complete webpage HTML saving.
8.  No context-menu activation in Version 1.
9.  No injected webpage button in Version 1.
10. All generated downloads must be placed under Downloads/Tender/.
11. Process tenders sequentially.
12. Preserve tender listing order.
13. Never bypass CAPTCHA, login, access restrictions, or security controls.
14. Restrict website access to www.jobz.pk.
15. Use defensive selectors and readable error messages.
16. Do not collect or upload user information.
17. Store duplicate history locally in the extension.
18. Implement one development phase at a time.
19. Never begin the next phase automatically.
20. Preserve previously completed functionality.
